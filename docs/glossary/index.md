# 术语表（Glossary）

本页用于快速查询。详细定义、公式、适用条件和文献依据见对应知识页。

| 缩写或术语 | 英文全称 | 中文与知识入口 |
|---|---|---|
| LLM | Large Language Model | [大语言模型](../foundations/language-models/index.md) |
| LVLM | Large Vision-Language Model | [大型视觉语言模型](../foundations/vision-language-models/lvlm-overview.md) |
| UQ | Uncertainty Quantification | [不确定性量化](../uncertainty/index.md) |
| NLL | Negative Log-Likelihood | [负对数似然](../foundations/probability-information-theory/negative-log-likelihood.md) |
| ECE | Expected Calibration Error | [期望校准误差](../evaluation/calibration-metrics/expected-calibration-error.md) |
| AUROC | Area Under the Receiver Operating Characteristic Curve | [受试者工作特征曲线下面积](../evaluation/detection-metrics/auroc.md) |
| AUPRC | Area Under the Precision-Recall Curve | [精确率–召回率曲线下面积](../evaluation/detection-metrics/auprc.md) |
| AURC | Area Under the Risk-Coverage Curve | [风险–覆盖率曲线下面积](../evaluation/selective-prediction/aurc.md) |
| Factuality | Factuality | [事实性](../hallucination/factuality.md) |
| Faithfulness | Faithfulness | [忠实性](../hallucination/faithfulness.md) |
| Robustness | Robustness | [鲁棒性](../hallucination/robustness.md) |
| Verbal Confidence | Verbal Confidence；文献别名 Verbalized Confidence | [语言自报置信度](../uncertainty/verbal-confidence/index.md) |
| Semantic Entropy | Semantic Entropy | [语义熵](../uncertainty/sampling-based/semantic-entropy.md) |
| Visual Grounding | Visual Grounding | [视觉定位](../foundations/vision-language-models/visual-grounding.md) |

正文统一使用“拒答”表示 Abstention，使用“黑盒／白盒”描述相应访问条件；实际能读取哪些信息仍须逐项说明，见[UQ 分类](../uncertainty/uq-taxonomy.md)。token、prompt、logits、embedding、hidden state、benchmark、checkpoint、fine-tuning、inference、sampling 和 decoding 保留英文原词。
