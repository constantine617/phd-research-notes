# 研究问题（Research Questions）

本页区分长期研究问题与当前可通过实验逐步收敛的问题。长期对象是大语言模型（Large Language Model，LLM）与大型视觉语言模型（Large Vision-Language Model，LVLM）的可信性（Trustworthiness）。当前以不确定性量化（Uncertainty Quantification，UQ）为主要技术方向，重点研究幻觉（Hallucination）与错误检测。以下问题用于指导研究选择，具体方法仍保持开放。

## 长期问题（Long-term Questions）

### 如何判断并改善模型输出的可信性？

怎样分别评估事实性（Factuality）、忠实性（Faithfulness）与鲁棒性（Robustness）？如何根据事实依据、输入支持和扰动条件，识别不同的问题输出？进一步，检测结果能否帮助选择有效的缓解方式？

这个问题既包括评估，也包括模型改进。研究需要说明怎样判断输出有问题、方法处理了哪类问题，以及在哪些条件下仍然失效。

### 图文信息的表示与交互如何影响多模态可信性？

多模态表征（Multimodal Representation）与跨模态对齐（Cross-modal Alignment）如何影响回答对图像和文本的使用？模型生成缺乏视觉依据的内容时，能否从图文对应关系、信息遗漏或训练方式中找到可检验的原因？

这个问题为表征、对齐、证据利用和模型训练保留研究空间。后续技术选择应与实际观察到的错误类型相对应。

### 可信性方法在医疗任务中需要满足哪些条件？

通用任务中得到的可靠性信号，在医学图像与文本共同参与时是否仍然有效？当医学知识正确性与具体输入支持需要分别判断时，怎样设计相应评估？哪些错误需要通过领域数据进一步分析？

这个问题将医疗应用作为长期检验场景，关注方法适用性的变化及其原因。

## 当前问题（Current Questions）

### 哪些不确定性信号能够帮助识别幻觉或错误输出？

输出概率、不同回答之间的语义差异，以及模型自报的置信度（Confidence），各自能识别哪些问题？面对正确、错误和缺乏证据支持的回答时，它们的表现是否一致？尤其需要检查高置信度错误与低置信度正确的情况，并分析检测失败的原因。

### 置信度能否与观察到的正确率相匹配？

置信度校准（Confidence Calibration）研究中，所报告的数值是否与相应回答的正确情况相符？校准前后，错误检测能力与置信度数值的含义分别发生了什么变化？当任务或模型改变时，这种匹配关系能否保持？

### 在有限计算预算下，哪些 UQ 信息值得保留？

高效 UQ（Efficient UQ）需要考察：增加 sampling 或额外模型调用，能换来多少检测或校准收益？只使用一次生成，或减少重复生成时，哪些错误更容易被遗漏？比较时应同时检查效果与实际计算成本。

### 模型内部表征能够提供哪些额外信息？

基于表征的 UQ（Representation-based UQ）能否从 hidden state 中找到输出概率或回答一致性未能体现的可靠性信息？这些信号在不同任务和模型设置下是否稳定？获得这些信息需要怎样的模型访问条件和额外计算？

### 外部或多模态证据能够补充哪些判断依据？

外部证据（External Evidence）与多模态证据（Multimodal Evidence）能否帮助判断模型反复生成、但缺乏依据的回答？引入检索文本或图像后，检测与校准是否改善？当证据本身不完整或不可靠时，所得信号又应如何解释？

当前问题将通过代表性方法比较、错误分析和初步实验继续收敛，具体推进方式见[当前研究重点（Current Focus）](current-focus.md)。
