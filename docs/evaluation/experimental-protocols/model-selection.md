# 模型选择

模型选择应服务于研究问题与信息需求。比较 LLM 或 LVLM 时，仅写模型家族名称无法定位实际实验对象。

## 建立模型记录

[Mitchell et al. (2019)](https://doi.org/10.1145/3287560.3287596 "文献引用") 的 Model Cards 提供记录模型版本、设计用途、评价条件与群体差异的框架。研究实验可进一步明确：

- 家族、参数规模、发布者、发布日期与精确 checkpoint。
- 基础模型还是经过指令 fine-tuning 的模型，是否还有其他训练阶段。
- 开放权重还是接口访问，是否能取得 logits、token 概率或 hidden state。
- 接口模型标识、可固定的版本、调用日期与服务返回的版本信息。
- 精度、量化、上下文长度、聊天模板，以及视觉编码器和图像预处理。

无法取得的信息记为未知。例如接口没有公开内部参数量，就不根据相近产品名称补写。

## 比较需要控制的因素

概率方法需要可靠的 log probability 接口，表征方法需要内部信息，多次 sampling 方法需要足够调用预算。若某模型不支持所需访问方式，应把方法不可用与方法失败分开。

同一系列不同规模有助于研究规模变化，但训练数据和训练策略也可能同时变化；不能无条件把所有差异解释为参数量的因果作用。基础模型与指令模型的输出格式不同，答案提取失败应单独分析。

## 覆盖范围与模型选择偏差

先说明选择哪些模型是为了检验跨家族、开放与闭源、或文本与视觉的迁移。不要只保留方法最有效的模型。若研究只在一个模型验证，就将结论限制于该模型与设置。

模型版本变化可能同时改变基础错误率和置信度分布。重新比较时应保存旧结果，并重新检查校准与阈值；不可将不同版本结果拼成一个看似同时完成的实验。
